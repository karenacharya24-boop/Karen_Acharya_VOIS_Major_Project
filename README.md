# Seasonal Agriculture Performance Analysis

## VOIS Major Project

**Student:** Karen Acharya

### Project Overview

This project analyzes agricultural performance across different seasons
using data analytics and visualization techniques.

The analysis focuses on:

- Seasonal agricultural performance
- Crop yield and production
- Profit and economic performance
- Environmental conditions
- Irrigation methods
- Water usage and efficiency
- Correlation analysis
- Statistical testing using ANOVA

### Dataset

The dataset contains agricultural records covering different:

- States
- Districts
- Crops
- Seasons
- Irrigation methods
- Environmental conditions
- Resource usage
- Economic measures

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Google Colab / Jupyter Notebook

### Key Findings

- Kharif showed the highest average yield.
- Kharif showed the highest average profit.
- Zaid showed comparatively lower yield and profit.
- Sugarcane recorded the highest average yield among crops.
- Drip irrigation recorded the highest average yield among irrigation methods.
- Nitrogen was the strongest independent-variable correlation with yield.
- ANOVA resulted in a p-value of 0.233, indicating no statistically significant difference in average yield between seasons.
